## Hardware and Firmware

To recognize an AT3 device, we can use the Hardware and the Firmware. The
Hardware represents the physical type of the AT3 product, while the Firmware
represents the binary code loaded into it. For example, a device could:

* be a Compact Tracker;
* and be flashed with _AT3 : 1.2-0_ which is its Firmware version.

By linking a pair of Hardware and Firmware to a Parameter Set, when a
device communicates, the Configuration Manager will associate this
device to a Parameter Set, and so to a list of Configurations.

Firmware selected in this page will make
visible the Parameter Set linked to it in the **Configurations** page.

From here you can access a list containing different versions, that
are grouped by device type. You can select Firmwares by clicking the
checkbox, then **Save my choice**: it updates the Parameter Sets and Configurations shown.

Only the checked Firmware versions are visible in the **Configurations** page.
