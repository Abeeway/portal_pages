## Hardware and Firmware

To recognize a AT3 device, we can use the Hardware and the Firmware. The
Hardware represents the physical type of the AT3 product, when the Firmware
represents the binary code loaded into it. For example, a device could:

* be a Compact Tracker ;
* and be flashed with _AT3 : 1.2-0_ which is its Firmware version.

By linking a pair of Hardware and Firmware to a Parameter Set, when a
device communicates, the Configuration Manager will associate this
device to a Parameter Set, and so to a list of Configuration.

Firmware selected in this page will make
visible the Parameter Set linked to it in the **Configuration and
Parameter** page.

From here you can access to a list containing different versions, that
are grouped by device type. You bcan select Firmwares by clicking the
checkbox, it will update data shown for Parameter Set and Configuration.

Only the checked FW versions will be visible in the **Configurations & Parameters** menu.
